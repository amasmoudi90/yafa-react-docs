# YAFA React docs

Documentation of the YAFA React theme for Salla stores, in Arabic and English.

Live site: https://amasmoudi90.github.io/yafa-react-docs/

```bash
npm install
npm run dev     # local preview
npm run build   # static site in docs/.vitepress/dist
```

Every push to `main` publishes the site through GitHub Pages (`.github/workflows/deploy.yml`).
