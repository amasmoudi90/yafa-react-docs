# Theme settings

These settings are in the theme editor, in about this order. The editor shows them in Arabic; each section below gives the Arabic label in brackets to help you find it.

## Dark / light mode (إعدادات الوضع الداكن / النهاري)

| Setting | What it does | Suggested |
|---|---|---|
| Store default mode (الوضع الافتراضي للمتجر) | The mode a visitor sees on the first visit: light or dark. Afterwards the store remembers the visitor's choice | Your brand's choice |
| Prevent changing the default mode (منع تغيير الوضع الافتراضي) | Hides the switch, so the store always uses the default mode | Off |

## Logo (إعدادات الشعار)

| Setting | What it does | Suggested |
|---|---|---|
| Logo per dark / light mode (تخصيص الشعار حسب الوضع) | Allows a different logo per mode | On if your dark logo disappears on the dark background |
| Logo in dark mode | Shown in dark mode | Transparent PNG, light colours |
| Logo in light mode | Shown in light mode | Transparent PNG, dark colours |

Without this option, the store logo from your Salla settings is used in both modes.

## Footer (خيارات أسفل الصفحة)

| Setting | What it does |
|---|---|
| Dark mode (الوضع الداكن) | A footer with a dark background |

## Product page and product card (خيارات صفحة المنتج)

| Setting | What it does | Suggested |
|---|---|---|
| Improved add-to-cart notice | A small window with the product's image and price after adding it to the cart | On |
| Sticky add button and quantity on phones | A bar fixed at the bottom of the product page on phones, with the price, quantity and add button | On |
| Show tags | The product's tags under the product page | On |
| Product gallery image display | "Cover" fills the frame; "contain" shows the whole image without cropping | Contain for products on white, cover for fashion photos |
| Rating on the product card | Rating stars on the card | On |
| Out-of-stock badge on the card image | A badge over the image of unavailable products | On |
| Discount countdown on the product card | A countdown to the end of the discount | On |
| Remove decimal zeros (halalas) | Shows 100 instead of 100.00 | On |
| WhatsApp button on the product page | A WhatsApp contact button on the product page | On |
| WhatsApp button text / link | The button's text and chat link | A link like `https://wa.me/966500000000` |
| Promotional title colour | The colour of the promotional title badge on cards and the product page | Your brand colours |

## Navigation and promotional bar

| Setting | What it does | Suggested |
|---|---|---|
| Navigation bar design on large screens (تصميم شريط التنقل) | "Default": the menu runs across the header. "Side navigation bar": the menu opens in a side panel from the menu button | Default for a few sections, side bar for many |
| Promotional text bar (تفعيل ميزة النص الترويجي) | A bar of texts above the header | On, with at least one text |
| Promotional texts | Per text: the text, a link, a text colour | One to three short texts |
| Promotional bar background colour | The bar's colour | A colour that contrasts with the text |
| Auto-animate the promotional bar | Rotates through the texts | On with more than one text |

## Store colours (تخصيص ألوان المتجر)

| Setting | What it does |
|---|---|
| Customize store colours | Turns on the colours below |
| Background colour 1 / 2 | The page background and the secondary background of some sections |
| Soft background colour | The background of cards and boxes |
| Heading colour / description colour | The colour of headings and texts |
| Primary colour in dark mode | Buttons and links in dark mode |

Each setting exists for light mode and for dark mode. The primary colour in light mode is your **store colour** from the Salla settings.

::: tip
The defaults are balanced and tested; change them with care and check both modes after each change.
:::

## Language and side menu

| Setting | What it does |

## Interactive cart

| Setting | What it does |
|---|---|
| Interactive cart (experimental) (تفعيل السلة التفاعلية) | A side cart that opens from the cart icon without leaving the page, for signed-in customers |

## Category page

**Texts and banners on the category page** (اضافة نصوص و بنرات في صفحة التصنيفات): a list with one item per category you want to enrich:

| Field | What it does |
|---|---|
| Category | The category it applies to |
| Category text | A paragraph above the category's products (Arabic and English) |
| Banner 1 / 2 / 3 | Up to three banner images above the products |
| Similar products | A products section at the bottom of the page |
| Products / categories / chosen products / number | The source of the similar products: one or more categories, offers, latest or products you pick; 4, 8, 12 or 16 products |

## Custom font (تخصيص الخط)

| Setting | What it does |
|---|---|
| Custom font | Replaces the store font with a font you choose |
| Font link | The font's CSS link, for example from Google Fonts |
| Font name | The family name as in the link, for example `Cairo` |

Example: the link `https://fonts.googleapis.com/css2?family=Cairo:wght@400;700&display=swap` and the name `Cairo`. The store font stays as a fallback if the font fails to load.

## Floating WhatsApp button

| Setting | What it does |
|---|---|
| WhatsApp button on every page | A floating button in a corner of the screen |
| WhatsApp chat link | `https://wa.me/` followed by your number in international format, without zeros or + |

## Loader

| Setting | What it does |
|---|---|
| Loader | A screen shown until the page has loaded |
| Loader text | The text under the image, for example "Loading ..." |
| Loader image | Your logo on a transparent background, or an animated GIF |

## Pop-up on first load (النافذة المنبثقة)

Shown once per visit; it closes with its button or by clicking outside it.

| Setting | What it does |
|---|---|
| Pop-up | Turns the pop-up on |
| Title / description | The pop-up's text |
| Animated word in the title | A word shown in a colour that moves between purple and pink |
| Tags | Small buttons under the description (2 to 4) |
| Image | An optional side image (square) |
| Action button text / link | For example "Shop the offers" linking to the offers page |
