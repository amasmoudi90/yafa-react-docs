# Content in two languages

YAFA supports Arabic (right to left) and English (left to right). The theme's own texts (buttons, menus, messages) are translated. **Your content** you enter in both languages yourself.

## What you translate

| Content | Where |
|---|---|
| Product names and descriptions | Salla dashboard: each product, English tab |
| Categories and brands | Salla dashboard |
| Menus, pages and articles | Salla dashboard |
| Titles and texts of home page blocks | Theme editor: multilingual fields have a box per language |
| Category page texts | The "texts and banners on the category page" setting: text in Arabic and English |

::: warning
If you leave an English field empty, the Arabic content shows in the English version of the store.
:::

## Images and language

Banners with text written on the image look the same in both languages. Prefer a banner without written text, and type the title and description in the block's fields: they then follow the visitor's language.

## Turning on English

1. Turn on English in Salla's language settings.
2. Turn on **Language option** in the theme settings so the language button shows in the header.
3. Open your store in English and review every page.
