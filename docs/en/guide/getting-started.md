# Getting started

YAFA React is a theme for Salla stores built on the **Twilight React** engine. It comes in Arabic and English, in light and dark mode, and works on phones, tablets and computers.

## 1. Install the theme

1. Open your Salla dashboard, then the **Store design** section.
2. Find **YAFA** in the theme store and install it.
3. Click **Customize** to open the theme editor.

::: tip
Try the theme in preview first, then publish it once your home page content is ready.
:::

## 2. Prepare your store basics

The theme reads these settings from your Salla dashboard, so check them first:

| Salla setting | Where it shows in the theme |
|---|---|
| Store logo, name and description | Header, footer and loader |
| Store colour | Main colour of buttons and links in light mode |
| Store font | The font of every page (unless you choose a custom font in the theme settings) |
| Languages and currencies | The language and currency button in the header |
| Menus | The main menu in the header and the footer links |
| Social links, tax number and commercial register | Footer |

## 3. Customize in three steps

1. **General settings**: default mode (light or dark), a logo per mode, the promotional bar, colours, WhatsApp buttons. See [Theme settings](./settings).
2. **Home page**: add and order the blocks, then fill in each block's fields. See [Home page blocks](./home-blocks).
3. **Category pages**: add a text, banners and suggested products to your main categories. See [Store pages](./pages).

## 4. Review your store

- Open the store in Arabic, then in English.
- Try light and dark mode from the sun / moon button in the header.
- Open the store on your phone.
- Add a product to the cart and go on to checkout.

::: info Images
Use good quality images with consistent sizes within a block, and add a **phone image** wherever a block offers one: banners look much better on phones.
:::
