# FAQ

### How do I make dark mode the default?
In the settings: **Store default mode** → dark. New visitors see dark mode and can switch with the sun / moon button, unless you turn on "Prevent changing the default mode".

### My logo doesn't show in dark mode
Turn on **Logo per dark / light mode** and upload a light version of your logo for dark mode.

### Why is there Arabic text in the English version?
Because the English field is empty. See [Content in two languages](./languages).

### How do I change the button colour?
In light mode the primary colour is your store colour from the Salla settings. For dark mode: **Primary colour in dark mode** in the theme settings.

### The banner is cropped on phones
Add a **phone image** to the banner, in a tall size (about 800×1000).

### How do I use a Google Fonts font?
Turn on **Custom font**, then paste the font link and family name. See [Custom font](./settings#custom-font-تخصيص-الخط).

### The side cart doesn't open
The **interactive cart** works for signed-in customers. Check that it is on in the settings.

### How do I hide the promotional bar?
Turn off **Promotional text bar**.

### How do I add my branch's map?
Add the **Store location (Google Maps)** block: in Google Maps choose "Share" → "Embed a map", and copy only the link inside `src="..."`.

### Does the theme work on slower connections?
The theme loads images and blocks further down the page only when the visitor reaches them, so the first screen appears quickly even on an average connection.
