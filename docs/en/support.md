# Support

Before contacting us, check the [FAQ](./guide/faq) and the [theme settings](./guide/settings): most questions are answered there.

## How to reach us

- **Email**: [amasmoudi90@gmail.com](mailto:amasmoudi90@gmail.com)
- **From the Salla theme store**: the YAFA theme page → Support.

## To help us help you quickly

Send us:

1. Your store's link.
2. The page with the problem (home, a product, a category…).
3. The device and browser (phone / computer, Chrome / Safari…).
4. The store language and mode (light / dark) when the problem appears.
5. A screenshot if you can.
