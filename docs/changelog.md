# سجل التحديثات

## الإصدار ١.٠ (قريباً)

الإصدار الأول من ثيم يافا على محرك Twilight React من سلة:

- ٣٢ عنصراً للصفحة الرئيسية، منها صانع البانرات بالشبكة، المنتجات بترتيب، والمنتجات بتبويب.
- الوضعان النهاري والداكن، بألوان وشعار لكل وضع.
- العربية والإنجليزية في كل الصفحات.
- صفحة منتج جديدة بشريط إضافة ثابت على الجوال، وشراء سريع، وزر واتساب.
- صفحات التصنيفات بنصوص وبانرات ومنتجات مقترحة، وفلاتر في درج جانبي على الجوال.
- السلة الجانبية التفاعلية وإشعار الإضافة للسلة.
- حساب العميل: الملف الشخصي، الطلبات، قائمة الأمنيات، الإشعارات، المحفظة.
- خط مخصص، مؤشر فأرة مميز، شاشة تحميل، نافذة ترحيب.
