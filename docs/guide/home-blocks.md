# عناصر الصفحة الرئيسية

تُبنى الصفحة الرئيسية من **عناصر** تضيفها وترتّبها من محرر الثيم، ثم تملأ حقول كل عنصر. يمكنك إضافة العنصر نفسه أكثر من مرة بمحتوى مختلف.

## حقول مشتركة

معظم العناصر تحتوي هذه الحقول:

| الحقل | ما يفعله |
|---|---|
| عنوان العنصر / فقرة وصف العنصر | العنوان والفقرة أعلى العنصر |
| اتجاه العنصر | «في المنتصف» (عنوان في الوسط مع خط زخرفي) أو «في البداية» (عنوان على الجانب بخط ملون، مع رابط «عرض الكل» أو أسهم التنقل بجانبه) |
| لون الخلفية | اللون الأول أو الثاني للخلفية من [ألوان المتجر](./settings#ألوان-المتجر) |
| مصدر المنتجات | تصنيف أو أكثر، التخفيضات، الأحدث، أو منتجات مختارة |
| عدد العناصر في الصف | للجوال والجهاز اللوحي والحاسوب، في العناصر المتحركة |
| الهامش الخارجي | يعرض العنصر داخل حاوية بهوامش، أو بعرض الشاشة كاملاً |

## البانرات والوسائط

### صانع بانر متحرك او عدة بانرز
سلايدر بانرات احترافي: لكل بانر صورة للحاسوب وأخرى للجوال، عنوان ووصف بحجم ولون تختارهما، زر متحرك برابط، موضع المحتوى (أعلى / وسط / أسفل، بداية / وسط / نهاية)، وصورة جانبية اختيارية بجانب النص. مثالي كأول عنصر في الصفحة.

::: tip مقاسات مقترحة
صورة الحاسوب نحو 1920×800 وصورة الجوال نحو 800×1000.
:::

### صانع بانر ثابت او عدة بانرز
البانرات نفسها في شبكة بدل السلايدر: تختار عدد الأعمدة لكل شاشة، وعرض كل بانر (كم عموداً يأخذ). البانر كله رابط واحد.

### بانرات متحركة
بانرات صور فقط (صورة حاسوب وصورة جوال ورابط)، مع عدد البانرات في الصف لكل شاشة (١ إلى ٦) وتحريك تلقائي.

### بانر ثابت او عدة بانرز ثابتين
بانر أو أكثر في شبكة، بعنوان اختياري للعنصر، مع التحكم بعدد الأعمدة وعرض كل بانر.

### يافا - بانران
بانران متجاوران، لكل منهما صورة وعنوان ووصف وزر برابط.

### يافا - الهيرو
قسم افتتاحي بعنوان ووصف وزر، مع فيديو خلفية اختياري (MP4/WebM أو يوتيوب).

### يافا - قسم الفيديو
فيديو MP4 بعرض الصفحة أو داخل حاوية، مع زر اختياري لتشغيل الصوت.

### يافا - يوتيوب
فيديو يوتيوب بمعرّفه (الجزء بعد `v=` في الرابط).

### يافا - فاصل
مسافة بين عنصرين، بخط فاصل أو بدونه، وهامش عمودي تختاره (٠ إلى ٢٥٦ بكسل).

## الروابط السريعة

روابط بصورة وعنوان إلى تصنيفاتك أو صفحاتك، بأربعة تصاميم:

| العنصر | الشكل |
|---|---|
| روابط سريعة (التصميم 1) | بطاقات بصورة وعنوان، متحركة أو في شبكة |
| روابط سريعة (التصميم 2) | صور دائرية / مربعة صغيرة مع العنوان تحتها، حتى ٨ في الصف |
| روابط سريعة (التصميم 3) | بطاقات بعنوان وعنوان فرعي، مع اختيار شكل الزوايا ونسبة الصورة (مربعة أو طولية ٢:٣) والظل |
| روابط سريعة (تصميم فسيفسائي) | سبعة مربعات بأحجام مختلفة في تصميم فسيفسائي |

## المنتجات

| العنصر | ما يعرضه |
|---|---|
| منتجات ثابتة | شبكة منتجات من المصدر الذي تختاره (٤ إلى ٣٢ منتجاً)، مع رابط «عرض الكل» |
| منتجات متحركة | سلايدر منتجات مع أسهم ونقاط تنقل وتحريك تلقائي |
| منتجات متحركة مع بانر | بانر بخلفية وعنوان وزر بجانب سلايدر منتجات |
| منتجات ثابتة بترتيب | المنتجات التي تختارها بالترتيب الذي تحدده تماماً |
| منتجات ثابتة بتبويب | تبويبات، لكل تبويب عنوانه ومصدر منتجاته؛ يُفتح التبويب الأول |
| منتجات متحركة بتبويب | التبويبات نفسها مع سلايدر منتجات متحرك في كل تبويب |
| عنصر منتج | منتج واحد مميز بصوره وسعره وزر الإضافة للسلة |
| الماركات التجارية | شعارات الماركات التي تختارها في سلايدر متحرك |

## المحتوى والثقة

| العنصر | ما يعرضه |
|---|---|
| مميزات المتجر (التصميم 1 / 2 / 3) | مزايا متجرك بأيقونة ولون خلفية للأيقونة وعنوان ووصف، بثلاثة تصاميم مختلفة |
| ارقام المتجر | أرقام تُعدّ تصاعدياً عند ظهورها (عدد العملاء، المنتجات…)، من ٢ إلى ٤ |
| عنصر خطوات للمتجر | خطوات مرقّمة (مثل خطوات الشراء)، من ٢ إلى ٤ |
| محتوى تعريفي متقدم | عنوان ونص منسّق وزر مع صورة، وفيديو يعمل عند الضغط على الصورة، مع خيارات ترتيب النص والصورة |
| الأسئلة المتداولة | أسئلة وأجوبة قابلة للطي (حتى ١٥) |
| المدونة | مقالات من مدونة متجرك |
| موقع المتجر (خرائط قوقل) | خريطة فرعك: من Google Maps اختر «مشاركة» ثم «تضمين خريطة» وانسخ الرابط من داخل الكود |

## العروض والتواصل

| العنصر | ما يعرضه |
|---|---|
| عنصر التخفيضات (مع امكانية وضع كوبون) | نص ترويجي وعدّاد تنازلي حتى تاريخ انتهاء العرض، وكوبون ينسخه العميل بضغطة، وزر إلى صفحة العروض، بلونين تختارهما |
| عنصر التواصل (واتساب ومواقع التواصل) | عنوان وزر إلى واتساب متجرك أو رابط تختاره، مع روابط مواقع التواصل |

## عناصر سلة المدمجة

تظهر أيضاً في المحرر عناصر من سلة نفسها بتصميم يافا:

- **آراء العملاء**: تقييمات متجرك في سلايدر.
- **آراء عملاء عشوائية**: مجموعة متغيرة من تقييمات المتجر.
- **منتجات متحركة** (من سلة): سلايدر منتجات بتصميم بطاقات يافا.

## نصائح للصفحة الرئيسية

- ابدأ ببانر قوي، ثم روابط سريعة للتصنيفات، ثم منتجات.
- نوّع بين العناصر ولا تكرر النوع نفسه متتالياً.
- استخدم «يافا - فاصل» لضبط المسافات.
- جرّب الصفحة على الجوال: معظم الزوار يتسوقون منه.
